🚀 How to Host on GitHub Pages & Structure NotebookLM JSONs

1. Save File: Save this entire code file as index.html in the root of your GitHub Repository.

2. Upload Lecture JSONs: Create a folder named /lectures and upload your NotebookLM JSON files (e.g., renal_biochem_l1.json).

3. Expected NotebookLM JSON Schema:

[
  {
    "id": "biochem_l1_01",
    "subject": "Biochemistry",
    "lecture": "Renal Transporters & Acid-Base",
    "question": "Which luminal transporter in the proximal convoluted tubule is directly targeted by acetazolamide?",
    "options": [
      "Sodium-Glucose Cotransporter 2 (SGLT2)",
      "Sodium-Hydrogen Exchanger 3 (NHE3) via Carbonic Anhydrase Inhibition",
      "Sodium-Potassium-2Chloride Cotransporter (NKCC2)",
      "Thiazide-sensitive NaCl Cotransporter (NCC)"
    ],
    "answer": 1,
    "explanation": "Acetazolamide inhibits carbonic anhydrase (CA II intracellularly and CA IV brush border), reducing HCO3- reabsorption and impairing NHE3 Na+/H+ exchange."
  }
]

4. Enable Pages: In your GitHub repository settings, navigate to Pages → Branch: main / root → Save. Your personal quiz bank will be live instantly!
